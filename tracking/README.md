# Progress records

requirements.json is the fixed 26-skill core checklist. scenarios.json is the fixed 32-case catalogue with execution state. Start at not_started, attach sanitised evidence for real results, and leave blocked items in the denominator. The readable matrix is docs/12-requirements-matrix.md; scoring rules are docs/07-validation-and-coverage.md. tools/validate_repo.py checks consistency and prints actual recorded progress.
